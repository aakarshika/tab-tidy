# Security Policy

## Supported versions

Only the latest release of Tab Tidy gets security fixes.

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Report it privately through GitHub instead: go to the repo's [Security tab](https://github.com/aakarshika/tab-tidy/security) and click **Report a vulnerability**. Include what you found, how to reproduce it and what impact you think it has.

You should get a response within a week. Once the issue is confirmed and fixed, it will be disclosed in the release notes, with credit to you if you'd like.
